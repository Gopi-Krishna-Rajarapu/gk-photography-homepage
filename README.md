# gk-photography-homepage
A responsive photography studio website built with HTML and CSS, featuring a modern landing page, sidebar navigation, social media links, and photography-focused UI.

GK Photography
A simple and responsive photography-themed landing page with a slide-out
sidebar navigation menu. The project is built using HTML, CSS, Google
Fonts, and Font Awesome.

📌 Project Overview
GK Photography is a front-end photography website concept designed
for photography studios and photographers. The page contains:
- Photography-themed landing content
- Hero/introductory sections
- Sign-up button
- Hamburger menu for sidebar navigation
- Navigation links for Gallery, Shortcuts, Exhibits, Events, Store,
  Contact, and Feedback
- Social media icons
- Font Awesome icons
- Poppins Google Font
🛠️ Technologies Used
- HTML5 -- Website structure and semantic markup
- CSS3 -- Styling and layout
- Google Fonts -- Poppins font
- Font Awesome 6.4.0 -- Navigation and social media icons
  
📂 Project Structure
GK-Photography/
│
├── index.html
├── sidebar.css
└── README.md
index.html contains the main webpage structure, while sidebar.css
contains the styling for the page and sidebar menu.

✨ Features
1. Photography Landing Section
The page introduces the photography brand with:
GK PHOTOGRAPHY
and a short description for photography studios and photographers.
2. Hero Section
The main section contains:
- "Discover and share the world's best photos"
- Supporting description
- Sign Up button
3. Sidebar Navigation
The sidebar includes:
- Gallery
- Shortcuts
- Exhibits
- Events
- Store
- Contact
- Feedback
4. Hamburger Menu
A checkbox-based menu system is used to open and close the sidebar.
The menu uses:
- fa-bars for the open button
- fa-xmark for the close button
5. Social Media Section
Social icons are included for:
- Facebook
- Twitter
- Instagram
- YouTube
  
🚀 How to Run
Option 1: Open Directly
1. Download or clone the project.
2. Make sure index.html and sidebar.css are in the same folder.
3. Double-click index.html.
Option 2: Using VS Code
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select Open with Live Server.
The website will open in your browser.

🎨 Customization
You can customize the project by modifying sidebar.css.
Possible improvements include:
- Adding a photography gallery
- Adding real navigation links
- Adding responsive layouts
- Adding image cards
- Adding animations and transitions
- Adding a contact form
- Adding a photographer portfolio section
- Adding dark/light mode
- Connecting the Sign Up button to a registration page
📱 Responsive Design
The HTML includes the viewport meta tag:
<meta name="viewport" content="width=device-width, initial-scale=1.0">
This allows the page to adapt to different screen sizes when the CSS
contains responsive rules.
